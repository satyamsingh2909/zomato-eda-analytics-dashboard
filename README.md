# 🍽️ Zomato EDA & Analytics Dashboard

An interactive Exploratory Data Analysis (EDA) and analytics dashboard built using Python, Pandas, Plotly, and Streamlit.

The project analyzes restaurant data to identify patterns and insights related to ratings, cuisines, pricing, delivery time, locations, and restaurant safety measures.

## 📊 Project Overview

This project follows a complete data analysis workflow:

Raw Dataset → Data Cleaning → Exploratory Data Analysis → Visualization → Interactive Dashboard

The final Streamlit dashboard allows users to interactively explore the dataset using filters and visualizations.

## ✨ Features

- 📊 Interactive restaurant analytics
- ⭐ Restaurant rating analysis
- 🍽️ Cuisine distribution and analysis
- 💰 Average price analysis
- 🚚 Delivery time analysis
- 📍 Location-based analysis
- 🔎 Restaurant search and filtering
- 📈 Interactive Plotly visualizations
- 🎛️ Dynamic Streamlit filters
- 🧹 Data cleaning and preprocessing

## 🛠️ Tech Stack

- **Python**
- **Pandas** — Data manipulation and analysis
- **NumPy** — Numerical operations
- **Plotly** — Interactive visualizations
- **Streamlit** — Interactive web dashboard
- **Jupyter Notebook** — Exploratory data analysis
